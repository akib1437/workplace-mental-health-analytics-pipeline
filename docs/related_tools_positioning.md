# Related-Tools Positioning

| Adjacent tool or approach | Primary capability | Difference from this artefact |
|---|---|---|
| Conventional psychometric scripts and packages | Scale scoring, reliability analysis, and exploratory psychometrics | The present artefact integrates configurable aggregate reporting boundaries, FDR-controlled subgroup analysis, disclosure logs, and execution provenance for workplace-survey reporting. |
| Statistical disclosure-control software | Formal protection of statistical tables through primary and secondary suppression and related disclosure methods | The present artefact uses a basic minimum-cell release rule and is not a substitute for formal statistical disclosure-control software. |
| Federated or non-disclosive analysis platforms | Distributed analysis across separated data sources with stronger governance controls | The present artefact is a lightweight local aggregate-reporting pipeline and does not provide federated analysis or formal privacy guarantees. |
| This configuration-driven pipeline | Configurable scoring, validation, eligibility checks, FDR adjustment, effect-size reporting, small-cell suppression, run manifests, and aggregate-only outputs | Narrowly focused on reproducible workplace mental-health survey reporting without clinical diagnosis, causal claims, or individual-level decision support. |
